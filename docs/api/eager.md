# Eager implementation

`EagerFrameLabeledArray` is the array-backed implementation of the
[protocol](protocol.md). It supports the full protocol and works with any array following
the [array API](https://data-apis.org/array-api/latest/), with tested support for NumPy and
JAX. See [Eager arrays](../guide/eager-arrays.md) for a guide.

::: polder.eager.array.EagerFrameLabeledArray
