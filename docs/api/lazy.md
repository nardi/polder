# Lazy implementation

`LazyFrameLabeledArray` is the implementation backed entirely by
[Narwhals](https://narwhals-dev.github.io/narwhals/) LazyFrames, which evaluates operations
lazily and stores data in a long, relational format. It is in early development and does not
yet support the whole protocol. See [Lazy arrays](../guide/lazy-arrays.md) for a guide,
including which features are available today.
